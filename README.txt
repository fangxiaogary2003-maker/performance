本版功能
- 原表 OKR 字段：承接目标、任务描述、交付物标准、交付时间、权重、员工总结、时效/质量自评、时效/质量上级评、综合得分、备注。
- 时效和质量各为 0—10 分；任务综合分为两项上级评分的均值。自评仅参考。
- 原表五项协作评价及标准，每项20%；原表六项核心素质及标准、当月典型事例，权重17/17/17/17/16/16%。
- HRBP按任务指定1—10名验收人；全部通过才验收完成。改派、退回重提、目标变更使旧轮次失效。
- 目标主管确认、员工本人确认；月中变更保留旧目标、交付材料和评价。
- 上级与HRBP核心素质明细评分；员工和验收人看不到他人的评分草稿。
- 特殊加分最多10分，由不同的直属上级与指定HRD顺序审批。红线最终归零，总分封顶100。
- 人员新增、编辑、岗位与角色、主管/HRBP/HRD关联、CSV导入、补充月份名单。
- 管理员可在人员管理中将飞书待开通申请绑定已有员工，或新建普通员工。
- 规则草稿与批准规则分开。评分主体、无协作任务处理、跨任务汇总、双门槛等级和优先级需要明确选择及批准依据。
- 缺评保留空值，不能当作0发布；有效0分可以保存和计算。
- 结果发布与归档固定明细、人员关系、规则、计算结果和审计记录；支持10个工作表的Excel、中文PDF导出。

群提醒：管理设置 → 飞书全员群提醒，填写群名称、Webhook及签名密钥，保存后发送测试；确认全员群收到，再启用定时推送。默认北京时间09:00，在每月前5个工作日各推送一条分阶段卡片。公司调休及假期仍按系统工作日历维护。

首次启用顺序
1. 人员管理：下载CSV模板，保留当前管理员行，补充真实名单；或逐个新增。
2. 先创建主管、HRBP、HRD人员并赋予对应角色，再填写员工关系。
3. 检查关系后点击“为本月生成考核单”。已生成月份保留当期关系，修改人员资料仅影响以后生成的考核单。
4. 员工先登录飞书；管理员在“飞书登录待开通”中核对姓名及本人编号，再绑定人员。
5. 管理设置：维护节假日及调休，确认月份日历；配置评分方案，确认政策选项，填写批准依据后创建规则并绑定月份。
6. 员工/主管制定目标，权重合计100%；主管确认，员工本人确认；HRBP逐项指定跨部门验收人。
7. 成果提交、验收、明细评分、加分审批；管理员核对完整性后发布、归档及导出。

原表参考口径
工作事项=OKR70%+协作30%，转换为百分制；核心素质=上级60%+HRBP40%，转换为百分制；总分=工作事项70%+核心素质30%+批准加分。
以上是原表参考权重，可以保存草稿；未绑定批准规则时不能正式算分和发布。双门槛及无协作情况按经批准的显式选项执行，不自行选定。
原Excel中错误的权重引用、固定除以2、缺评分当0、红线未归零等公式没有照抄。
