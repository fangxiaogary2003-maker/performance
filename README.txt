本次修正
原表的“跨部门评分”是独立月度评分，不再作为跨部门任务或逐项验收流程。
移除“多项跨部门任务如何汇总”“没有跨部门任务时”两个设置，以及当前考核的跨部门任务分类。
HRBP按员工及月份指定原Excel的两位异部门评分人；无需员工先填写任务，不得指定员工本人。
两位分别评响应效率、完成质量、问题解决、协作配合、专业赋能，每项0—10分、20%。
每个维度先取两人平均，再加权得到本月跨部门分；缺评不计0分，不用OKR替代。

员工与评分流程
员工填写OKR承接目标、任务描述、交付标准、期限、权重，主管及本人确认目标。
员工保存任务成果、时效及质量自评、备注和六项典型事例，提交整月绩效。
自评只参考。直属上级从飞书卡片进入，直接填写任务和核心素质评分，无需额外逐项验收。
整月提交后，已分派的两位月度跨部门评分人收到个人卡片；提交后才分派，同样自动通知。
卡片定位员工当月材料及五项评价，不要求另填跨部门任务。HRBP填写对应核心素质评分。
改派须有原因，保留历史，旧轮次评分及未发送卡片失效。整月退回立即收回评分人的材料访问权限。
重新提交需重新进行月度跨部门评价。上级撤回评分保存旧记录并创建新评分轮次。
特殊加分仍由直属上级与不同HRD顺序审批，红线归零，总分封顶100。

原表计算与等级
参考：工作事项70%、核心素质30%；工作内OKR70%、跨部门30%；核心素质内上级60%、HRBP40%。
OKR为上级时效和质量平均后按任务权重计算；跨部门五项各20%；核心素质六项17/17/17/17/16/16%。
优秀≥90；良好85至不足90；合格75至不足85；待改进70至不足75；不合格<70。
工作事项或核心素质任一模块<70，最终不合格；任一项70至不足75，最终最多待改进；两项均≥75后按总分判档。
工作100、核心63，总分88.9，最终不合格；核心72，总分91.6，最终待改进。加分不能抵消模块低分。
规则草稿不能用于正式发布。管理员须核对其余配置、填写批准依据、创建批准规则、绑定月份并确认公司日历。
本次不自动批准整套评分制度、填入真实分数或发布绩效。历史已发布档案和原规则保持原值。

界面与组织
普通员工使用本人单页待办；受邀跨部门评分时，同页展示本人当期待评员工。主管、HRBP、HRD按实际职责显示入口。
跨部门评分人只在整月提交后访问被分派员工材料，只见本人评分草稿；员工发布前不见他人数字评分。
管理员在人员管理顶部“同步飞书人员”，先读取预览再确认应用，保留既有飞书身份及当期考核关系。
从飞书读取姓名、部门、岗位、在职状态、直属上级；HRBP/HRD不能凭姓名或所在HR部门推定。

飞书通知与汇总
沿用现有自建应用、机器人和权限，不使用旧群Webhook。服务无需员工电脑开机。
每月前5个工作日、实际截止日和逾期工作日，北京时间09:00至18:00处理当天催办队列。
只催当前责任人的未完成事项：员工填报、主管评分、HRBP分派/核心评分、月度跨部门评分、加分审批。
管理员进度卡片包含员工、具体卡点、责任人及完整清单入口。
全部评分齐全后保存待发布汇总Excel并通知管理员；全部结果发布后生成正式汇总并再次通知。汇总仅管理员下载。
归档固定当月任务、两位跨部门五项、核心素质、规则、计算及审计，支持Excel/PDF导出。
消息随业务保存入队，发送前检查最新状态并去重；短时故障同uuid重试，超过去重窗口的不确定结果需管理员核对。
