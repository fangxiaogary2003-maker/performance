# 2026-11-11 外观优化

本次使用 UI UX Pro Max 的 Minimalism & Swiss Style 建议及可读性、触控、响应式规范，延续现有青绿色主色，统一员工、主管、HRBP、跨部门评分和管理员界面。产品布局检索没有适用命中；保留现有页面结构，采用技能的通用规范。营销页模式及深色金融仪表盘配色不适用于本系统，未采用。

## 修改边界

- 运行时仅变更 `app/globals.css` 及对应的 `selfhost/public/app.css`。
- 保留所有组件、事件、字段、导航入口及业务文件，前端可执行文件保持备份版本的原始字节。
- 评分权重、流程、权限、导出、接口、正式启用日期及消息计划不变。
- CSS 使用统一颜色变量、系统中文字体、清晰的正文层级、连续的间距和状态样式。
- 375px 下工作表延续原有卡片式呈现；管理表格在各自容器内滚动，页面不横向溢出。
- 统一焦点轮廓、移动端输入字号和触控高度；支持减少动态效果及系统高对比模式。
